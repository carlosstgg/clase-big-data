# Práctica 1.1 — Probabilidad y Estadística
## Análisis de la evolución poblacional mundial

Este proyecto contiene el análisis de la evolución poblacional mundial basado en los datos de Our World in Data (OWID), provenientes de United Nations, World Population Prospects (2024).

### Estructura del proyecto
- `data/raw/`: Datos originales utilizados en el análisis.
- `notebooks/`: Notebooks de Jupyter con el desarrollo de la práctica.
- `src/`: Código fuente adicional (si aplica).
- `requirements.txt`: Dependencias necesarias para ejecutar el proyecto.

### Ejecución
Para ejecutar el análisis, instale las dependencias y corra el notebook:
```bash
pip install -r requirements.txt
jupyter notebook notebooks/01_evolucion_poblacional.ipynb
```
